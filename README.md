# IndiPI
Laboratory kit for Industrial Information Technology based on Raspberry PI 5

## Description
A hands-on educational platform for learning industrial IoT and automation using Raspberry Pi 5.

## Getting Started
The Gerber files are available for creating your own kit. You would need the BOM described, an ADS analog-to-digital converter and a Raspberry PI 5. You can check the figures in order to know how to mount the whole kit.
